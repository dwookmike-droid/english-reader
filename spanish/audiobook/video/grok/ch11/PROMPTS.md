# 11장 장면 그림

11장 장면 4장. `00_refs` 그림이 다 있어야 시작한다.

## Instructions for Grok
- Make one image for each prompt below, in order. Use the prompt text exactly as written.
- Aspect ratio 16:9, landscape, the highest resolution available (1920×1080 or larger if possible).
- Same painting style in every image: soft watercolor and gouache book illustration.
- No readable text anywhere: no letters, numbers, signs, gate or platform signs, logos or watermarks. Shop signs, street signs, awnings and plaques stay blank, even when the prompt names a place. Letters, notebooks, maps, screens and dates show only soft illegible marks.
- Paint the scene all the way to every edge. Never leave a blank band, border or empty strip at the bottom.
- Subtitles are added later over the bottom third. Do not draw any bar, band, border or empty strip yourself: paint the scene all the way to every edge, with the floor, table, ground or water continuing naturally into the lower third. Keep every face, hand, key and important object in the upper two-thirds.
- Always a finished scene in its real place. Never a character sheet, never the same person twice, never people on a plain or blank background, never half of the frame left empty.
- If "Reference images" are listed (up to 3: people first, then an object or place), attach those files from the `00_refs` folder and keep the faces, hair, clothes, objects and rooms the same as in them. If only 2 can be attached, leave out the last one.
- File names: save each image as the name in its heading (for example `ch11_s01.png`).
  If you make more than one version, add `_1`, `_2`, `_3` before `.png` (for example `ch11_s01_1.png`).
- Save the images in this folder only.
