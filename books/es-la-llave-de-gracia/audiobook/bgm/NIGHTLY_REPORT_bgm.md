## 남은 문제 (BGM 담당 밖, 오디오북 세션 판단)
1. **자르는 지점이 곡 중간이다.** `pilot_mix.py`는 간주를 11초(시작 테마 14초, 끝 테마 40초)에서 자르고 3초 페이드를 준다. 그 지점 직전 1초 RMS가 −14.7 ~ −29.7 dB로, 연주가 이어지는 중에 페이드로 줄어든다. 장 파일의 음악 끝 0.5초는 −39.5 dB(6장 E_uneasy_a) ~ −55.6 dB. 끊긴 소리는 아니지만, 곡마다 10–12초 안의 조용한 지점에서 자르면 더 자연스럽다. 실측한 조용한 지점(200 ms RMS):

   | cue | 지금(11초) | 제안 지점 |
   |---|---|---|
   | A_light_a | −23.3 dB | 11.95초 (−30.3) |
   | A_light_b | −17.5 dB | 10.45초 (−29.6) |
   | B_mystery_a | −30.9 dB | 11.95초 (−35.4) |
   | B_mystery_b | −37.3 dB | 그대로 |
   | C_tender_a | −21.8 dB | 11.95초 (−26.5) |
   | C_tender_b | −16.2 dB | 10.45초 (−32.6) |
   | D_warm_a | −20.4 dB | 11.30초 (−30.0) |
   | D_warm_b | −21.7 dB | 11.70초 (−31.4) |
   | E_uneasy_a | −38.0 dB | 그대로 |
   | E_uneasy_b | −29.6 dB | 11.95초 (−32.7) |
   | F_bittersweet | −17.9 dB | 11.80초 (−25.5) |
   | theme_open (14초) | 직전 1초 −16.9 dB | 14.25초 (−25.5) |
   | theme_close (40초) | 직전 1초 −25.6 dB | 자르지 말고 50초 전부. 원곡이 끝 1초 −56 dB로 스스로 잦아든다 |

2. **장 파일의 true peak가 −0.6 ~ −1.3 dBTP다.** 1–9장 모두 최댓값이 말소리 구간에 있고 간주 구간이 아니다. 스포티파이는 손실 압축 전 −1 dBTP 이하를 권장하므로, 말소리 쪽 리미터를 검토할 필요가 있다.
3. `out/pilot/final/`은 11-10의 Gemini 음성 파일럿(1–9장)이다. 11-11부터 Voicebox로 바뀌었다면 새 음성으로 조립한 뒤 위 측정을 다시 해야 한다. 측정 스크립트: `~/Developer/audio-studio-mcp/bgm_scripts/qa_bgm.py`.
