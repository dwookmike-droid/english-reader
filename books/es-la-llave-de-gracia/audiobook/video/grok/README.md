# Grok 그림 작업 폴더

폴더 하나가 Grok 작업 하나다. 폴더마다 있는 `PROMPTS.md`를 Grok에 그대로 주면 된다.
Grok이 읽는 안내(영어), 만들 그림 목록, 그림마다 프롬프트가 들어 있다.

## 순서
1. `00_refs/`: 참고 그림 14장을 가장 먼저 만든다. 인물 10명, 시계, 열쇠, 부엌, 지하실.
2. 파일럿 `ch01/`, `ch02/`, `ch03/`: 장면 16장(6, 6, 4)
3. 나머지 `ch04/`–`ch30/`: 파일럿을 올린 뒤에 만든다.

## 파일 이름
| 종류 | 이름 | 예 |
|---|---|---|
| 참고 그림 | `ref_<이름>.png` | `00_refs/ref_yuna.png` |
| 장면 그림 | `chNN_sMM.png` (장 두 자리, 장면 두 자리) | `ch01/ch01_s03.png` |
| 같은 장면의 여러 버전 | 끝에 `_1`, `_2`, `_3` | `ch01/ch01_s03_2.png` |

- 확장자는 `.png`, `.jpg`, `.jpeg`, `.webp` 모두 된다.
- 버전이 여럿이면 쓸 파일 하나를 골라 이름에서 `_숫자`를 지운다. 예: `ch01_s03_2.png` → `ch01_s03.png`. 나머지는 그대로 둬도 된다.
- 장면 번호는 `scenes.tsv`, 오디오 시간표와 같다. 번호를 바꾸면 화면이 엉뚱한 때 바뀐다.

## 다시 만들 그림
- 글자, 간판, 로고, 워터마크가 보인다.
- 사람 수나 인물이 장면 설명과 다르다. 윤하는 38세 한국 여성, 몬세는 73세로 윤하 어깨까지 오는 작은 키.
- 같은 인물의 얼굴, 머리, 옷이 참고 그림과 많이 다르다.
- 아래쪽 1/3에 중요한 물건이나 얼굴이 있다. 그 자리는 자막 띠가 가린다.
- 화풍이 수채·과슈가 아니다(사진풍, 3D, 만화풍).

## 그림을 넣은 뒤
```bash
python3 collect.py 1 2 3      # 1–3장 그림을 ../img/로 모은다
python3 collect.py --check    # 무엇이 없고, 무엇을 골라야 하는지만 본다
```
`collect.py`가 정해진 이름(없으면 하나뿐인 버전)을 PNG로 바꿔 `../img/chNN_sMM.png`에 넣는다.
`render.py`는 그 그림을 읽고, 그림이 없는 장면에는 임시 그림을 쓴다.

## 프롬프트를 고칠 때
`../scenes.tsv`나 `../style.md`를 고친 뒤 이 폴더에서 차례로 돌린다. 이미 넣은 그림은 지워지지 않는다.
`make_folders.py`는 기본으로 4장부터만 다시 쓴다(1–3장은 이미 작업함). 전부 다시 쓰려면 `--all`.

4장부터 바뀐 규칙(2026-11-10, 1·2장 검수 결과):
- 간판·거리 표지·차양은 비워 둔다. 지명이 프롬프트에 있어도 쓰지 않는다(2장 s05_2에 'PLAÇA DE LA…'가 나왔다).
- 편지·수첩·지도·화면·연도는 알아볼 수 없는 선으로만.
- 영상의 아래 1/3은 검은 자막 띠가 덮는다. 얼굴·손·열쇠·중요한 물건은 위 2/3에.
- 참고 그림은 최대 3장: 인물 2장(드문 인물 먼저) + 시계·열쇠·지하실·몬세 부엌 중 하나. Grok이 2장만 받으면 마지막 것을 뺀다.
```bash
python3 build.py
python3 make_folders.py
```
